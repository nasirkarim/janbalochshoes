# JAN BALOCH SHOES STORE — Authentic Pakistani Footwear Collection

A complete, modern, and visually stunning e-commerce frontend website for **JAN BALOCH SHOES STORE**, dedicated to artisan Pakistani footwear, traditional Balochi Chawat, Peshawari chappals, embroidered bridal khussas, executive formal footwear, and contemporary sneakers.

---

## 🌟 100+ Authentic Pakistani Footwear Styles

The store features a curated catalog of **100 distinct footwear products** divided into two dedicated lines:

### 1. Men's & Boys' Footwear Collection (50 Styles)
- **Traditional Peshawari Chappal**: Norozi cuts, Kaptaan chappal, Zalmi cuts, tire-sole classics, buffalo leather chappal.
- **Balochi Traditional Collection (Balochi Chawat)**: Balochi Chawat footwear, traditional Balochi leather footwear, embroidered Balochi sandals, and cultural heritage leather craft.
- **Pakistani Ethnic Footwear**: Kolhapuri-style chappals, men's embroidered wedding tilla khussa, festive footwear.
- **Leather Sandals & Comfort Slippers**: Double-strap sandals, cross-strap sandals, outdoor walking sandals, minimalist leather home slippers.
- **Formal Footwear**: Executive formal black Oxfords, heritage brown Derbies, monkstraps, Italian penny loafers.
- **Contemporary Casuals**: Pure white sneakers, stealth black sneakers, knit runners, canvas shoes, relaxed driver loafers.

### 2. Women's & Girls' Footwear Collection (50 Styles)
- **Traditional Pakistani Khussa & Juttis**: Handcrafted dabka khussa, royal golden wedding khussa, silver festive khussa, rangoli multicolor khussa, floral silk embroidered khussa, mirror-work sheesha khussa.
- **Balochi-Inspired Women's Footwear**: Balochi embroidered women's flats, traditional Balochi Chawat-inspired footwear.
- **Bridal & Festive Footwear**: Pakistani wedding zari flats, pearl-embellished ivory flats, mehndi function yellow khussa, Eid festive velvet khussa, golden glitter party sandals, block-heel festive sandals.
- **Ladies' Sandals & Daily Chappal**: Hand-braided leather sandals, cross-strap slides, double-strap comfort sandals, soft everyday chappals.
- **Flats & Loafers**: Minimalist pointed flats, hand-burnished leather flats, women's tailored loafers, formal ballet flats.
- **Women's Casual & Sneakers**: Active white sneakers, black lightweight casual sneakers, cloud-comfort slip-ons.

- **Color Selector**: Black, Tan, Brown, Gold, Silver, Mustard, White, Red, Green.
- **Price Range Slider**: Rs. 2,500 – Rs. 10,000.

## 🚀 Running the Project

The server is configured to run on **Port 5000**:

```bash
npm run dev
```

Open in browser:
👉 **[http://localhost:5000](http://localhost:5000)** or **[http://127.0.0.1:5000](http://127.0.0.1:5000)**

### Production Build:
```bash
npm run build
```
Generates an optimized static bundle in the `dist/` directory with 0 errors.
